# skills/

In diesem Verzeichnis liegen die installierten Skills von AI-Orb.

Jeder Skill ist ein eigenes Unterverzeichnis mit `skill.json`, `skill.py`,
Tests und Dokumentation. Skills werden nicht von Hand hierher kopiert,
sondern über AI-Orb installiert – dabei werden sie geprüft, ihre
Berechtigungen werden dir vorgelegt, und erst nach deiner Bestätigung wird
installiert.

Wie du eigene Skills schreibst, steht in `docs/SKILLS.md`.
